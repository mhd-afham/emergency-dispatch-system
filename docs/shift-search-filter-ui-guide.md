## Filter Options Reference

### Type Filter Dropdown:
- All Types (shows all)
- Regular
- Overtime
- Emergency

### Status Filter Dropdown:

- Planned
- Active
- Completed
- Cancelled

### Staffing Filter Dropdown:
- All Staffing (shows all)
- Fully Staffed (100%)
- Partially Staffed (1-99%)

## Color Coding

### Filter Badge Colors:
- 🔵 Blue: Search query
- 🟣 Purple: Type filter
- 🟢 Green: Status filter
- 🟠 Orange: Staffing filter
- 🌸 Pink: Date filters

### Button Colors:
- 🟢 Green: "Export to PDF" button
- 🔴 Red: "Clear All" button (for filters)
- 🔵 Blue: Action buttons (View, Edit, Manage)

## Example Usage Scenarios

### Scenario 1: Find Emergency Shifts This Week
```
1. Set "From Date" to: Today (Oct 21)
2. Set "To Date" to: +7 days (Oct 28)
3. Set "Type" to: Emergency
4. Click "Export to PDF" to save results
```

### Scenario 2: Review Understaffed Shifts
```
1. Set "Staffing" to: Partially Staffed
2. Set "Status" to: Planned
3. Review shifts in table
4. Use "Manage" button to assign crew
```

### Scenario 3: Generate Monthly Report
```
1. Set "From Date" to: Oct 1, 2025
2. Set "To Date" to: Oct 31, 2025
3. Leave other filters as "All"
4. Click "Export to PDF"
5. Share PDF with administration
```

### Scenario 4: Search for Specific Station
```
1. Type station name in search bar: "Central"
2. Results automatically filter
3. Apply additional filters if needed
```

## Responsive Behavior

### Desktop (Wide Screen):
- 5 filter dropdowns in single row
- Search bar and export button side by side
- Filter badges displayed horizontally
- Full table visible

### Tablet (Medium Screen):
- 2 columns for filter dropdowns
- Search and export button stack
- Filter badges wrap to multiple lines
- Table scrolls horizontally if needed

### Mobile (Small Screen):
- 1 column layout (vertical stack)
- All filters stacked vertically
- Search bar full width
- Export button full width below search
- Filter badges stack vertically
- Table scrolls horizontally

## Performance Considerations

- **Instant Filtering**: No API calls for filtering
- **Real-time Search**: Updates as you type
- **Client-side PDF**: No server processing needed
- **Efficient Rendering**: Only visible shifts rendered
- **Lazy Loading**: PDF generated on demand

## Tips for Best Results

1. **Start Broad, Then Narrow**: Begin with fewer filters, add more as needed
2. **Use Date Ranges**: Most effective for time-based analysis
3. **Combine Filters**: Mix multiple filters for precise results
4. **Save PDFs with Descriptive Names**: Rename after download for easy reference
5. **Clear Filters Between Searches**: Use "Clear All" for fresh start
