# Shift Search, Filter, and PDF Export Feature

## Overview
Added comprehensive search, filter, and PDF export functionality to the Shift Management system in the Supervisor Dashboard.

## Date Implemented
October 21, 2025

## Features Implemented

### 1. Search Functionality
- **Search Bar**: Real-time search across shift names and station names
- **Visual Feedback**: Search icon in input field
- **Case Insensitive**: Searches work regardless of letter case

### 2. Advanced Filtering System

#### Filter Options:
1. **Date Range Filter**
   - From Date: Filter shifts starting from a specific date
   - To Date: Filter shifts up to a specific date
   - Both can be used together or independently

2. **Type Filter**
   - All Types (default)
   - Regular shifts
   - Overtime shifts
   - Emergency shifts

3. **Status Filter**
   - All Status (default)
   - Planned
   - Active
   - Completed
   - Cancelled

4. **Staffing Level Filter**
   - All Staffing (default)
   - Fully Staffed (100% staffed)
   - Partially Staffed (1-99% staffed)
   - Not Staffed (0% staffed)

#### Filter Features:
- **Multiple Filters**: All filters can be combined for precise filtering
- **Active Filter Display**: Shows colored badges for each active filter
- **Results Counter**: Displays "Showing X of Y shifts"
- **Clear Filters Button**: One-click to reset all filters
- **No Results Message**: Helpful message when no shifts match filters

### 3. PDF Export Functionality

#### PDF Generation Features:
- **Professional Layout**: Multi-page PDF with proper formatting
- **Automatic Filename**: `shifts_report_YYYY-MM-DD.pdf`
- **Success Notification**: Confirms PDF generation with filename

#### PDF Content Sections:

1. **Header Section**
   - Report title
   - Generation timestamp
   - Generated by (user name)

2. **Summary Statistics**
   - Total shifts in report
   - Active shifts count
   - Fully staffed count
   - Understaffed count
   - Empty shifts count

3. **Applied Filters**
   - Lists all active filters applied to the report
   - Helps understand the report scope

4. **Main Table** (Page 1)
   - Shift Name
   - Date
   - Time (start - end)
   - Type
   - Status
   - Crew count (assigned/required)
   - Staffing percentage
   - Station name
   - Professional grid layout with alternating row colors

5. **Detailed Shift Information** (Additional Pages)
   - Full shift details for each shift
   - Complete crew assignment list with:
     - Crew member names
     - Their roles
   - Proper pagination when content exceeds one page

6. **Footer**
   - Page numbers on every page (Page X of Y)

#### PDF Styling:
- **Color Scheme**: Professional blue headers with white text
- **Grid Layout**: Clear borders and organized structure
- **Alternating Rows**: Light gray for better readability
- **Font Sizes**: Optimized for printing and digital viewing
- **Margins**: Proper spacing throughout

## Usage Instructions

### For Users:

#### Searching Shifts:
1. Type in the search bar to find shifts by name or station
2. Results update in real-time as you type

#### Filtering Shifts:
1. Select date range using "From Date" and "To Date" pickers
2. Choose shift type from "Type" dropdown
3. Select status from "Status" dropdown
4. Choose staffing level from "Staffing" dropdown
5. Multiple filters work together (AND logic)
6. See active filters displayed as colored badges
7. Click "Clear All" to reset filters

#### Exporting to PDF:
1. Apply any desired filters first
2. Click the green "Export to PDF" button
3. PDF will be generated with filtered results
4. File automatically downloads to your Downloads folder
5. Success message appears confirming generation

### Filter Combinations Examples:

**Example 1: Find understaffed emergency shifts**
- Type: Emergency
- Staffing: Partially Staffed or Not Staffed

**Example 2: Upcoming shifts this week**
- From Date: Today
- To Date: Today + 7 days
- Status: Planned

**Example 3: Completed shifts last month**
- From Date: First day of last month
- To Date: Last day of last month
- Status: Completed
