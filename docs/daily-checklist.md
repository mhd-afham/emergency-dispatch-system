# ✅ Team Member Daily Checklist

## 📅 **Start of Each Coding Session**
- [ ] Open GitHub Desktop
- [ ] Verify I'm on MY branch (`[name]/[module]`)
- [ ] Click `Repository` → `Pull` to get latest changes
- [ ] Open code editor with project folder
- [ ] Check if any team updates in group chat

---

## 💻 **While Coding**
- [ ] Make small, logical changes
- [ ] Test my code regularly
- [ ] Save files frequently
- [ ] Review changes in GitHub Desktop periodically

---

## 📝 **When Ready to Commit**
- [ ] All files saved in editor
- [ ] GitHub Desktop shows my changes
- [ ] Review each changed file carefully
- [ ] Uncheck files I don't want to commit
- [ ] Write clear, descriptive commit message
- [ ] Click `Commit to [my-branch]`
- [ ] Click `Push origin` to upload changes

---

## 🔀 **Creating Pull Request (When Feature Complete)**
- [ ] All changes committed and pushed
- [ ] Feature is tested and working
- [ ] In GitHub Desktop: `Repository` → `Create Pull Request`
- [ ] **Base branch:** `development` (NOT main)
- [ ] **Compare branch:** My feature branch
- [ ] Fill out PR template completely
- [ ] Add clear title and description
- [ ] Click `Create Pull Request`
- [ ] Notify team in group chat

---

## 🚨 **Before Leaving Each Day**
- [ ] All work committed (no pending changes)
- [ ] Changes pushed to GitHub
- [ ] GitHub Desktop shows "No local changes"
- [ ] If stuck on something, noted in team chat

---

## 🆘 **If Something Goes Wrong**
- [ ] Don't panic - Git keeps history of everything
- [ ] Take screenshot of the error
- [ ] Ask in team group chat
- [ ] Contact Afham if it's repository-related

---

## 📊 **Weekly Self-Check**
- [ ] My branch is up to date with latest changes
- [ ] I'm following commit message standards
- [ ] My code is organized in appropriate folders
- [ ] I haven't accidentally modified others' modules
- [ ] PRs are targeting `development` not `main`

---

**Print this checklist and keep it handy! 📌**
