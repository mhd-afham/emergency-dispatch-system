# Adding Respondr Logo to PDF Reports

## Overview
This guide explains how to add the Respondr logo to the PDF reports generated by the Emergency Dispatch System.

3. **Final path should be**:

### Step 2: Recommended Logo Specifications
- **Format**: PNG (recommended for PDF compatibility)
- **Dimensions**: Approximately 500x150 pixels or similar aspect ratio
- **Background**: Transparent
- **Color**: Full color (red Respondr branding with black text)

## Code Changes Made

### Header Logo Implementation
**File**: `apps/web/src/components/admin/ReportGenerationSection.tsx`

The logo is now added to the **header section** of every PDF report:
- **Position**: Top-left corner (14, 12)
- **Size**: 50 x 15 units
- **Fallback**: If logo fails to load, displays "Respondr" text in brand red color

```typescript
// Header Logo Code
try {
  const logoPath = '/images/respondr-horizontal.png';
  const img = new Image();
  img.src = logoPath;
  doc.addImage(img, 'PNG', 14, yPosition - 3, 50, 15);
  yPosition += 14;
} catch (error) {
  // Text fallback
  doc.text('Respondr', 14, yPosition);
}
```

### Footer Logo Implementation
The logo is now added to the **footer section** of every page:
- **Position**: Bottom-left corner (14, pageHeight - 22)
- **Size**: 25 x 7.5 units (smaller than header)
- **Accompanies**: Page numbers, generation date, and subtitle

```typescript
// Footer Logo Code
for (let i = 1; i <= pageCount; i++) {
  doc.setPage(i);
  
  try {
    const footerLogoPath = '/images/respondr-horizontal.png';
    const footerImg = new Image();
    footerImg.src = footerLogoPath;
    doc.addImage(footerImg, 'PNG', 14, pageHeight - 22, 25, 7.5);
  } catch (error) {
    // Text fallback
    doc.text('Respondr', 14, pageHeight - 14);
  }
}
```
